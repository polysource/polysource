# Polysource Showcase Demo — ShopCo SaaS

> **Hero of the v0.1.0 launch.** A single Symfony 7.4 LTS application
> exercising the **15 Polysource packages** in a coherent e-commerce
> SaaS scenario. See [ADR-025](../../docs/adr/0025-showcase-demo.md)
> for the rationale.

For a screenshotted walkthrough, see
[`docs/user/showcase-tour.md`](../../docs/user/showcase-tour.md).

![ShopCo dashboard](../../docs/user/screenshots/02-home-dashboard.png)

## Run

```bash
# From the repo root
make showcase
```

Then open http://localhost:8084/.

| Login | Password | Role | Sees |
|---|---|---|---|
| `admin@shop.co` | `shopco` | `ROLE_ADMIN` | Everything (incl. purge / GDPR export) |
| `ops@shop.co` | `shopco` | `ROLE_OPS` | Reads + retry / cancel / transition |
| `viewer@shop.co` | `shopco` | `ROLE_VIEWER` | Read-only |

## What's exercised

| Phase | Package | Demo surface |
|---|---|---|
| C | `easyadmin-filter-bridge` + `filter` | 4 EA CRUDs (Product, Customer, Order, Refund) with 8 enhanced filters + 4 custom bridge filters |
| D | `symfony-bundle` + `adapter-messenger` + `adapter-doctrine` | 50 failed envelopes, 300 login attempts (Doctrine cohabitation) |
| E | 4 non-Doctrine adapters (`redis`, `flysystem`, `http`, `meilisearch`) | 30 cache keys, 15 S3 files, 3 microservices, 200 indexed products |
| F | `audit`, `workflow-bridge`, `widgets`, `search`, `bulk-async` | 50 audit entries, OrderWorkflow state machine, 6-widget home dashboard, Cmd+K palette, 8 bulk jobs |
| G | Permissions + saved views | 3-role voter, 3 default saved views |
| H | Symfony Panther E2E | 3 unauthenticated journey tests |
| I | Screenshots pipeline | 14 PNGs auto-regenerated by `make screenshots` |

## Make targets

```text
make build         Build the PHP container image
make install       Install Composer deps
make up            Boot the stack + serve on :8084
make db            Reset + migrate the database
make fixtures      Load Foundry fixtures + seed messenger/redis/minio/meilisearch
make assets        Compile AssetMapper public/ files
make down          Stop the stack (preserves volumes)
make reset         Stop and wipe ALL volumes (data loss)
make logs          Tail logs from all services
make shell         Shell in the PHP container
make test          Fast PHPUnit suite (excludes panther group)
make panther       Boot Selenium + run @group panther tests
make phpstan       Static analysis level max
make cs-fix        PSR-12 + Symfony rules
make screenshots   Regenerate docs/user/screenshots/ (14 PNGs)
make clean         Stop + remove vendor/, var/, build artefacts
```

## Tests

The showcase ships two test suites:

- **WebTestCase** — fast, in-process, covers EasyAdmin CRUDs +
  Polysource standalone resources + per-role permissions matrix
  (`PermissionsByRoleTest`). 22 tests / 51 assertions.
- **Panther E2E** — Selenium Chromium driving the real browser, 3
  unauthenticated journey tests (login page renders, firewall
  redirects). Authenticated journeys are exercised by the
  WebTestCase + the `app:showcase:screenshots` command.

```bash
make test          # 22 tests, < 5s
make panther       # 3 tests, ~10s (chrome boot included)
```
