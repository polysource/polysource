# v0.9.0 — Architectural cleanup

> Audit conducted 2026-05-17 across the 16-package monorepo. Five
> parallel passes (workarounds, cross-package coupling, god classes,
> security, DRY). 23 work items, prioritised for a single release
> train: `v0.9.0 — règles de l'art`.

---

## Scope & ground rules

- **Out of scope:** new features, performance work, new ADRs unrelated to the
  findings, public announce.
- **In scope:** every finding below, batched into ≤7 PRs to keep CI parallel
  and review surfaces tight.
- **Non-negotiable:** zero workarounds, zero `// for now`, zero silent
  `catch(\Throwable)` introduced. Every interface contract honest, every
  test green, every package independently installable.
- **Gate:** `make smoke` (path repos) before tag, `make smoke-packagist` +
  `make smoke-packagist-bridge` after tag, video-move dogfood install
  to validate.
