# `polysource/workflow-bridge` — Symfony Workflow integration

`polysource/workflow-bridge` is a Symfony bundle that turns any
Polysource resource into a Workflow-aware admin: per-transition
inline actions are auto-generated, the current state is rendered
as a Bootstrap chip, and every transition is captured by the
audit log (ADR-020) without extra wiring.

The whole thing is opt-in — a resource implements the marker
interface `WorkflowAwareInterface` and the bridge takes over.
Resources that don't implement it stay unchanged.

Per [ADR-021](../../adr/0021-symfony-workflow-bridge.md), this
ships as a **separate package** rather than baked into
`polysource/symfony-bundle`. Apps that don't use Symfony Workflow
pay no cost.

## Status

Pre-v0.1.0. Public API per ADR-021:
- `WorkflowAwareInterface` + `WorkflowAwareTrait`
- `WorkflowResolver` (Registry wrapper)
- `TransitionDiscovery` (delegates to Symfony's `Workflow::getEnabledTransitions()`)
- `ApplyTransitionAction` (one per transition, auto-generated by `TransitionActionFactory`)
- `WorkflowChipPalette` + `WorkflowChipExtension` (`polysource_workflow_chip_palette()` + `polysource_workflow_state_label()`)
- `_state_chip.html.twig` partial
- Bundle config: `polysource_workflow_bridge.palettes.<workflow>.<state> → string`

## Why this matters

Existing Symfony admin tools (EasyAdmin, Sonata, API Platform)
require hand-rolled actions per transition + manual chip
rendering. That's verbose, drift-prone, and disconnected from
the Workflow component's guard logic.

`polysource/workflow-bridge` is the only Symfony admin
solution that:
- Auto-generates transitions as inline actions (with per-transition
  permission attributes for granular access control).
- Delegates `getEnabledTransitions()` to the Workflow component —
  no guard re-implementation.
- Surfaces a Bootstrap state chip with a host-overridable palette.
- Wires through the audit log (ADR-020) for free —
  `actionName = transition-<name>`, `outcome = success | failure`.

Concretely this unblocks ecommerce / CRM / claims-management /
HR / regulated workflows where a state machine is the natural
abstraction.
